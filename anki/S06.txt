Why does <code>run: echo "OS: $OS"</code> (plain scalar) fail to parse?	<code>: </code> inside a plain YAML scalar is read as a mapping separator. Use a block scalar <code>|</code>.	WF WF-08 S6
What is the default <code>run</code> shell on Windows runners?	PowerShell (<code>pwsh</code>).	WF WF-09 S6
How do you read an environment variable in PowerShell?	<code>$env:NAME</code>	WF WF-10 S6
How do you set the same shell for all <code>run</code> steps in a job?	<code>defaults:</code> &rarr; <code>run:</code> &rarr; <code>shell: bash</code> at job level.	WF WF-11 S6
Which bash is used when <code>shell: bash</code> is set on Windows?	The bash included with Git for Windows.	WF WF-12 S6
Why does <code>echo "a\nb"</code> in bash print a literal <code>\n</code>?	bash <code>echo</code> does not interpret backslash escapes without <code>-e</code>.	WF WF-13 S6
What is a context in GitHub Actions?	An object with information about the run, the runner, variables, etc., read with <code>${{ context.property }}</code>.	CTX CTX-01 S6
What does <code>github.actor</code> contain?	The username of the user who triggered the initial workflow run.	CTX CTX-02 S6
What do <code>runner.os</code> and <code>runner.name</code> contain?	<code>runner.os</code>: the runner's operating system (<code>Linux</code>, <code>Windows</code>, <code>macOS</code>). <code>runner.name</code>: the name of the runner executing the job.	CTX CTX-05 S6
At which levels can <code>env</code> be defined, and which wins on conflict?	Workflow, job, step. The most specific (closest) level wins: step &gt; job &gt; workflow.	CTX CTX-06 S6
What is the difference between <code>vars</code> and <code>secrets</code>?	<code>vars</code>: non-sensitive configuration, shown in logs. <code>secrets</code>: sensitive values, masked as <code>***</code> in logs.	CTX CTX-07 S6
Which context holds the matrix values: <code>matrix</code> or <code>strategy</code>?	<code>matrix</code> (e.g. <code>matrix.os</code>). <code>strategy</code> only has <code>fail-fast</code>, <code>job-index</code>, <code>job-total</code>, <code>max-parallel</code>.	CTX CTX-08 S6
What do <code>strategy.job-index</code> and <code>strategy.job-total</code> contain?	The zero-based index of the current matrix job and the total number of matrix jobs.	CTX CTX-09 S6
What does <code>needs.&lt;job_id&gt;.result</code> contain?	The result of a job in <code>needs</code>: <code>success</code>, <code>failure</code>, <code>cancelled</code> or <code>skipped</code>.	CTX CTX-10 S6
What do you need to read <code>steps.&lt;id&gt;.outcome</code>?	Give the earlier step an <code>id</code>. Only steps that ran before the current step are available.	CTX CTX-11 S6
What are the possible values of <code>job.status</code>?	<code>success</code>, <code>failure</code>, <code>cancelled</code> (no <code>in_progress</code>).	CTX CTX-13 S6
Which contexts are available in <code>jobs.&lt;job_id&gt;.if</code>?	<code>github</code>, <code>needs</code>, <code>vars</code>, <code>inputs</code>.	CTX CTX-14 S6
Why is the <code>runner</code> context not available in <code>jobs.&lt;job_id&gt;.if</code>?	That key is evaluated by GitHub before the job is sent to a runner, so runner information does not exist yet.	CTX CTX-15 S6
What does a nonexistent context property evaluate to?	An empty string.	CTX CTX-17 S6
Who substitutes <code>${{ github.actor }}</code> and who substitutes <code>$ACTOR</code>?	GitHub substitutes <code>${{ }}</code> before the script runs; the shell (e.g. bash) substitutes <code>$ACTOR</code>.	EXP EXP-02 S6
How does the runner mask secrets in logs?	It replaces exact matches of secret values used in the job with <code>***</code>.	EXP EXP-08 S6
Why is secret masking not a guarantee?	It relies on exact matches; transformed values (e.g. Base64, reversed, split) are not masked.	EXP EXP-09 S6
Why should you not use structured data (JSON, YAML) as a secret?	Redaction relies on exact matches, so structured data reduces the chance of correct masking.	EXP EXP-10 S6
What should you do if a secret appears unmasked in a log?	Delete the log and rotate the secret.	EXP EXP-11 S6
What does a matrix strategy do?	Runs the same job multiple times, once per combination of matrix values.	MTX MTX-01 S6
How do you use a matrix value in <code>runs-on</code>?	<code>runs-on: ${{ matrix.os }}</code>	MTX MTX-02 S6
Where does a status like <code>in_progress</code> come from, if not <code>job.status</code>?	From the REST API / run list <code>status</code> field (<code>queued</code>, <code>in_progress</code>, <code>completed</code>), which describes the phase from outside.	API API-01 S6
Who can read all repository secrets indirectly?	Any user with write access to the repository.	SCV SCV-04 S6
Are secrets passed to workflows triggered from a forked repository?	No, except <code>GITHUB_TOKEN</code>.	SCV SCV-05 S6
What must you do if a secret value is committed to a repository?	Treat it as compromised and rotate it. It stays in the Git history even after the file is changed.	SCV SCV-06 S6
Which <code>github</code> context values are untrusted input?	Values attackers can control, e.g. PR title/body, <code>github.head_ref</code>, commit messages, issue/comment bodies.	INJ INJ-02 S6
Why use an intermediate <code>env</code> variable instead of <code>${{ }}</code> directly in <code>run</code>?	To prevent script injection: the value is passed as data, not pasted into the script as code.	INJ INJ-03 S6
