Which event lets you start a workflow manually from the Actions tab?	<code>workflow_dispatch</code>
Where must a <code>workflow_dispatch</code> workflow exist for the "Run workflow" button to appear?	On the default branch.
Which keys define a <code>workflow_dispatch</code> input in this lab?	<code>description</code>, <code>required</code>, <code>type</code> (e.g. <code>string</code>) and <code>default</code>.
How do you read a <code>workflow_dispatch</code> input named <code>recipient</code>?	<code>${{ inputs.recipient }}</code>
What is <code>${{ }}</code> in GitHub Actions?	Expression syntax. GitHub evaluates it and substitutes the result into the workflow text before the shell runs.
