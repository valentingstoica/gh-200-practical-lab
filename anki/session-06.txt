What is a context in GitHub Actions?	An object with information about the run, the runner, variables, etc., read with <code>${{ context.property }}</code>.
Who substitutes <code>${{ github.actor }}</code> and who substitutes <code>$ACTOR</code>?	GitHub substitutes <code>${{ }}</code> before the script runs; the shell (e.g. bash) substitutes <code>$ACTOR</code>.
What does <code>github.actor</code> contain?	The username of the user who triggered the initial workflow run.
Which contexts are available in <code>jobs.&lt;job_id&gt;.if</code>?	<code>github</code>, <code>needs</code>, <code>vars</code>, <code>inputs</code>.
Why is the <code>runner</code> context not available in <code>jobs.&lt;job_id&gt;.if</code>?	That key is evaluated by GitHub before the job is sent to a runner, so runner information does not exist yet.
Why use an intermediate <code>env</code> variable instead of <code>${{ }}</code> directly in <code>run</code>?	To prevent script injection: the value is passed as data, not pasted into the script as code.
Which <code>github</code> context values are untrusted input?	Values attackers can control, e.g. PR title/body, <code>github.head_ref</code>, commit messages, issue/comment bodies.
At which levels can <code>env</code> be defined, and which wins on conflict?	Workflow, job, step. The most specific (closest) level wins: step &gt; job &gt; workflow.
What is the difference between <code>vars</code> and <code>secrets</code>?	<code>vars</code>: non-sensitive configuration, shown in logs. <code>secrets</code>: sensitive values, masked as <code>***</code> in logs.
How does the runner mask secrets in logs?	It replaces exact matches of secret values used in the job with <code>***</code>.
Why is secret masking not a guarantee?	It relies on exact matches; transformed values (e.g. Base64, reversed, split) are not masked.
What should you do if a secret appears unmasked in a log?	Delete the log and rotate the secret.
Who can read all repository secrets indirectly?	Any user with write access to the repository.
Are secrets passed to workflows triggered from a forked repository?	No, except <code>GITHUB_TOKEN</code>.
Why should you not use structured data (JSON, YAML) as a secret?	Redaction relies on exact matches, so structured data reduces the chance of correct masking.
What does a matrix strategy do?	Runs the same job multiple times, once per combination of matrix values.
How do you use a matrix value in <code>runs-on</code>?	<code>runs-on: ${{ matrix.os }}</code>
What do <code>strategy.job-index</code> and <code>strategy.job-total</code> contain?	The zero-based index of the current matrix job and the total number of matrix jobs.
What is the default <code>run</code> shell on Windows runners?	PowerShell (<code>pwsh</code>).
How do you read an environment variable in PowerShell?	<code>$env:NAME</code>
How do you set the same shell for all <code>run</code> steps in a job?	<code>defaults:</code> → <code>run:</code> → <code>shell: bash</code> at job level.
Which bash is used when <code>shell: bash</code> is set on Windows?	The bash included with Git for Windows.
What does <code>needs.&lt;job_id&gt;.result</code> contain?	The result of a job in <code>needs</code>: <code>success</code>, <code>failure</code>, <code>cancelled</code> or <code>skipped</code>.
What do you need to read <code>steps.&lt;id&gt;.outcome</code>?	Give the earlier step an <code>id</code>. Only steps that ran before the current step are available.
What are the possible values of <code>job.status</code>?	<code>success</code>, <code>failure</code>, <code>cancelled</code> (no <code>in_progress</code>).
Where does a job status like <code>in_progress</code> come from, if not <code>job.status</code>?	From the REST API / run list <code>status</code> field (e.g. <code>queued</code>, <code>in_progress</code>, <code>completed</code>), which describes the job phase from outside.
What does a nonexistent context property evaluate to?	An empty string.
Why does <code>run: echo "OS: $OS"</code> (plain scalar) fail to parse?	<code>: </code> inside a plain YAML scalar is read as a mapping separator. Use a block scalar <code>|</code>.
Why does <code>echo "a\nb"</code> in bash print a literal <code>\n</code>?	bash <code>echo</code> does not interpret backslash escapes without <code>-e</code>.
