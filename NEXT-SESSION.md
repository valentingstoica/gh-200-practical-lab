# Next Session

## Singurul task propus

Publicarea ramurii locale pe GitHub și rularea manuală a primului workflow.

## Înainte de execuție

Asistentul va explica:

- ce publică primul `push` și cum stabilește ramura implicită pe GitHub;
- de ce workflow-ul trebuie să existe pe GitHub pentru a putea fi executat;
- cum funcționează evenimentul manual `workflow_dispatch`;
- unde se pornește workflow-ul și unde se urmăresc jobul, pașii și logurile;
- ce fișiere intenționează să modifice;
- care este criteriul de finalizare al sesiunii.

Publicarea va începe numai după aprobarea explicită a utilizatorului. Niciun
commit și niciun push nu vor fi efectuate fără cereri directe și neechivoce.

## Rezultat urmărit

Ramura locală este publicată în repository-ul GitHub, primul workflow este
declanșat manual, iar rezultatul jobului și al fiecărui pas este observat.
